# 栽培記録 (saibai-log)

個人利用の水耕栽培記録PWA。スマホ（Android）とPCのブラウザで動作する。

- **URL**: https://haradsan.github.io/saibai-log/
- データはすべて端末内（IndexedDB）に保存される。このリポジトリにデータは含まれない
- ビルド不要のバニラJS。`index.html` / `app.js` / `style.css` / `sw.js` のみ

## 使い方（スマホ）

1. 上のURLをChromeで開く
2. メニューから「ホーム画面に追加」でインストール
3. 以後はオフラインでも動作する
